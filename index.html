2027 退稅教程

先付含稅價，
離境確認後退款。

日本已於2026年11月1日改用 Refund Method。以下按國稅廳、日本海關及福岡機場現行官方指引整理；原 Threads 貼文可作經驗參考，但不同店舖的退款平台、手續費及收款方式會不同。

01

購物時

在有 Tax-Free 標誌的店舖辦理，出示本人護照或店舖支援的 Visit Japan Web 資料；先支付含稅價。單一免稅店同日稅前消費合計須滿 ¥5,000。

02

保存資料及貨品

按店舖指示登記退款方式，保留收據、QR Code 及全部退稅貨品。退款可能扣除服務費；現金、信用卡或其他方式並非每間店都相同。

03

寄艙前做海關確認

到福岡機場國際線3樓南側 J–M 櫃位前，以稅關 KIOSK 掃描護照，或連接專用 Wi-Fi 後用 Visit Japan Web。GREEN 即完成；RED 要帶護照及貨品接受檢查。

04

確認後收退款

完成海關確認後才辦理登機及寄艙。選現金退款者在出境檢查後，到 HAKATA FOOD HALL 入口旁的專用端末／櫃位領取日圓；其他方式依店舖指示在網上辦理。

隨身準備

  • 本人護照
  • 所有退稅貨品
  • 收據、店舖 QR Code／退款資料
  • 已註冊 Visit Japan Web 的手機（可選）

避免失手

  • 未做海關確認前不要把貨品寄艙
  • 同一張購買紀錄少一件貨品，整張紀錄或不能確認
  • 退款方式及手續費以購買店舖為準
  • 不要假設每間店都可在機場領現金
福岡機場位置：稅關 KIOSK 在國際線3樓南側 J–M 櫃位前，06:00–21:00；現金退款端末／櫃位在出境檢查後、HAKATA FOOD HALL 入口旁。建議預留至少30–45分鐘彈性，實際輪候視當日人流。
